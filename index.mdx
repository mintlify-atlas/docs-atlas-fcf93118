Rakion Launcher Tools is a suite of open-source utilities for deploying and operating a private Rakion game server. It provides everything from a scheduled database maintenance service and a Windows registry fixer for clients, to PHP-based launcher authentication and a set of command-line texture file tools.

## Get Started

<Steps>
  <Step title="Import the database schema">
    Load `database/rakion_all.sql` into MySQL to create all required tables.
  </Step>
  <Step title="Deploy the PHP web backend">
    Copy the files in `source/web/` to your web server and edit `config.php` with your MySQL credentials.
  </Step>
  <Step title="Configure and run AutoQuery">
    Edit `Settings/Settings.ini` with your MySQL connection details and timer preferences, then run `AutoQuery.exe`.
  </Step>
  <Step title="Distribute FixLaunch to players">
    Build `FixLaunch` and give it to players so they can register their Rakion installation path in the Windows registry.
  </Step>
</Steps>
